## Perbaikan update

- Memperbaiki error **Failed to start embedded python interpreter: Failed to import encodings module** setelah pemasangan update.
- Restart membuat runtime baru, terpisah dari folder sementara versi lama.
- Pemasangan menunggu aplikasi dan proses runtime lama selesai sebelum mengganti EXE.
- Menambahkan pemeriksaan Windows terhadap restart EXE onefile yang benar-benar dikemas, termasuk pembersihan runtime lama dan cadangan EXE.

**Penting:** pengguna v2.4.0/v2.4.1 perlu mengunduh v2.4.2 dan mengganti EXE secara manual sekali; proses update versi lama belum memiliki perbaikan ini. Pengaturan dan profil tetap tersimpan.
