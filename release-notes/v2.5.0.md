## Apa yang baru

- Tombol pilihan **Indonesia / English**, dengan pilihan bahasa tersimpan otomatis.
- Halaman **Daftar server / Server list** dan tombol **Hubungkan / Connect** melalui tautan FiveM.
- Daftar awal: iMe RP, Satu Mimpi, Indopride, Garuda Prime, dan Seven Glory. Kode join diperiksa dari halaman Cfx.re pada 3 Oktober 2026.
- Daftar disinkronkan dari `servers.json` di GitHub saat dibuka, setiap 5 menit, dan melalui tombol Sync.
- Mengubah daftar server di GitHub tidak memerlukan rilis EXE baru.
- Daftar valid terakhir tetap tersedia jika offline atau data baru tidak valid.
- Sidebar dapat digulir agar tombol tetap terjangkau.

Whitelist dan antrean mengikuti aturan masing-masing server. Connect menggunakan registrasi FiveM di Windows; jalankan FiveM sekali jika diperlukan. Profil/cache tidak diubah otomatis saat Connect.

Pengguna v2.4.2 dapat memasang melalui Update sekarang. Pengguna v2.4.0/v2.4.1 harus mengganti EXE manual sekali karena bug updater versi tersebut.
