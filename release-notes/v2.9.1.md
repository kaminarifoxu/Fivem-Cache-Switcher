# GanoV 2.9.1 — Dialog penyimpanan bertema

- Konfirmasi arsip HDD dan pengembalian cache kini mengikuti tema terang/gelap GanoV.
- Diagram arah transfer, lokasi tujuan yang bisa diseleksi/disalin, dan tombol tindakan yang jelas.
- Mendukung bahasa Indonesia/English serta lokasi panjang dengan karakter Unicode.
- Tombol Batal mendapat fokus awal; Escape dan tombol tutup membatalkan operasi.
- Pemeriksaan Windows mencakup dialog asli serta pembatalan sebelum pemindahan cache.
