# GanoV-Cache-Switch v2.9.1

- Mempercepat transfer cache dengan mengurangi pemanggilan tasklist dari setiap file menjadi maksimal sekitar sekali per detik selama penyalinan. Dampak terbesar pada cache berisi banyak file kecil.
- Pemeriksaan tetap dilakukan sebelum menyalin, sebelum mempromosikan salinan, dan sebelum menghapus sumber. File besar juga diperiksa selama penyalinan.
- Verifikasi SHA-256, penyimpanan hasil ke drive, dan pemulihan transaksi tetap dipertahankan.

Kecepatan aktual mengikuti kondisi drive, ukuran file, dan aktivitas disk. Update setelah transfer sebelumnya selesai; jangan mengganti EXE saat transfer berjalan.
