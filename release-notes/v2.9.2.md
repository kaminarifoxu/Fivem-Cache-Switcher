# GanoV-Cache-Switch v2.9.2

- Lanjutkan transfer setelah crash tanpa menyalin ulang seluruh folder cache. File lengkap pada salinan sementara diperiksa SHA-256 dan dipakai kembali.
- Hanya file hilang, berubah, rusak, atau terpotong yang disalin ulang. File besar yang terputus tetap dimulai dari awal file tersebut.
- Kebutuhan ruang lanjutan menghitung data yang masih harus disalin, bukan seluruh cache.
- Verifikasi akhir, perlindungan sumber, penanda folder arsip, dan pemulihan transaksi tetap dipertahankan.

Sesudah membuka aplikasi kembali, sambungkan HDD yang sama lalu pilih Peralatan → Lanjutkan pemindahan. Jangan hapus folder sementara atau konfigurasi transaksi. Update setelah transfer berjalan selesai.
