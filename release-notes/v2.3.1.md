## Apa yang baru

- Pengaturan disimpan otomatis di `%LOCALAPPDATA%\GanoV-Cache-Switch`.
- Cukup bagikan EXE; file konfigurasi tidak perlu berada di samping aplikasi.

- Pengaturan tetap tersedia saat EXE dipindahkan atau diganti.
- Build EXE dan publikasi rilis dijalankan melalui GitHub Actions.
