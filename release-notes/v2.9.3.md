# GanoV-Cache-Switch v2.9.3

- Transfer baru menghitung SHA-256 sambil menyalin, mengurangi pembacaan penuh sumber dari tiga kali menjadi satu kali.
- Salinan tujuan tetap dibaca dan diverifikasi. Perubahan ukuran, waktu, identitas file, serta daftar file sumber diperiksa sebelum penghapusan.
- Transfer yang dilanjutkan tetap menghitung ulang checksum sumber untuk memvalidasi file sementara yang dapat dipakai kembali.
- Panel progres menampilkan kecepatan rata-rata tiap tahap, agar penyalinan dan pembacaan verifikasi dapat dibedakan.
- Sinkronisasi file ke drive dan pemulihan transaksi tetap dipertahankan.

Kecepatan tetap bergantung pada drive, banyaknya file kecil, antivirus, dan aktivitas disk. Pasang update setelah transfer yang sedang berjalan selesai.
