# v2.6.1

- Pemberitahuan update dan tombol Update sekarang terlihat di bagian bawah semua halaman, termasuk Server list.
- Progres download terlihat di bagian bawah aplikasi dan di dialog update.
- Dialog update menggunakan jendela Windows normal dan dibawa ke depan agar tidak tersembunyi di belakang aplikasi.
- Pemberitahuan update tetap tersedia setelah berganti bahasa.

Jika menggunakan versi sebelumnya, buka Tools / Peralatan → Check for update. Bila dialog tetap tidak terlihat, unduh EXE v2.6.1 dari halaman rilis satu kali.
