## Apa yang baru

- **Update langsung dari aplikasi:** klik **Update sekarang**, tanpa membuka GitHub di browser.
- Indikator progres selama EXE baru diunduh.
- Ukuran file dan SHA-256 diperiksa sebelum pemasangan.
- EXE lama diganti di lokasi yang sama, lalu versi baru dibuka otomatis; tidak membuat EXE bernomor tambahan.
- Pengaturan dan profil kota tetap tersimpan.
- Jika pemasangan tidak selesai, EXE lama tetap tersedia; kegagalan membuka versi baru memicu pemulihan EXE lama.

### Cara mulai

Pengguna versi sebelum 2.4.0 perlu mengganti EXE manual sekali. Setelah itu, update berikutnya cukup melalui aplikasi. Folder EXE harus dapat ditulis.

**Validasi:** 32 tes berhasil di Windows, termasuk penggantian file dan pemulihan saat simulasi gagal membuka versi baru. Pembaruan EXE saat aplikasi berjalan belum diuji menyeluruh pada komputer pengguna.
