# v2.5.1

- Pilihan Indonesia / English dipindahkan ke Peralatan (Tools).
- Kartu server menampilkan pemain online / kapasitas dan waktu pengambilan data FiveM. Diperbarui setiap menit saat halaman server dibuka dan setelah Sync server.
- Deskripsi mengikuti sv_projectDesc yang ditampilkan daftar server FiveM. Deskripsi asli dipertahankan dalam kedua bahasa.
- Open page membuka servers.fivem.net/servers/detail/<kode-server>. Connect tetap membuka FiveM.
- Jika jumlah pemain gagal diambil, tampilkan belum tersedia, bukan nol.

Daftar server tetap disinkronkan dari servers.json di GitHub tanpa update EXE. Jumlah pemain berasal dari snapshot API FiveM dan dapat tertunda dibandingkan permainan.
